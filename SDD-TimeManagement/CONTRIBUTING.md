# Contributing

Please follow the Project Constitution in /constitution.md. Key points:

- Tests required for new behaviors per constitution thresholds
- Open PRs against main; include description linking spec and tasks

Local workflow:
- Create a branch per task: git checkout -b feat/T-XXX-short-desc
- Run tests: npm test (backend)
