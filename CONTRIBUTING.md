# CONTRIBUTING

Guidelines
- Follow the Project Constitution at specs/001-time-management/constitution.md
- Work on feature branches: `git checkout -b feat/NNN-description`
- Run linters and tests locally before PR
- Write tests for new functionality (unit/integration)

PR process
1. Open a PR to main
2. Ensure CI passes (lint, unit, integration)
3. Request review from owner/maintainers

Code style
- Use ESLint with recommended rules (backend and frontend)
- Keep commits small and focused
