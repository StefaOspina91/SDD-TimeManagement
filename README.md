# Time Management

SDD project: Presence & Absence tracking for collaborators.

Purpose: allow collaborators (direct and outsourcing) to self-report absences (full day, time ranges, recurring) so teams can see availability without direct messages.

Quick start
1. Install: `npm install` in backend/ and frontend/
2. Dev: `docker-compose -f docker-compose.dev.yml up` (Postgres)
3. Backend: `cd backend && npm run dev`
4. Frontend: `cd frontend && npm start`

See /specs/001-time-management for SDD artifacts (constitution, spec, plan, tasks).
